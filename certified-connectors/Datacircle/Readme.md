# Datacircle
Find the best GTM APIs: who is best for each API and plan, with each plan's score out of 100.

## Publisher
[Datacircle](https://datacircle.dev)

## Prerequisites
None. The API is free and takes no key, at most 60 calls a minute from one address.

## Supported Operations
- `List the APIs` - Every API on the sheet, with its slug and its best plan.
- `Who is best for an API` - An API's plans, best first, each with its rank.
- `List the plans` - Plans of every API, by score, provider or price.
- `Get a provider` - One provider's plans and scores.

## Known issues and limitations
At most 60 calls a minute from one address.
