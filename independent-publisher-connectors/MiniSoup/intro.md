# MiniSoup Connector

## Overview
MiniSoup is a lightweight HTML parsing library for Microsoft Power Automate. This connector allows you to use simple HTML parsing capabilities inspired by Beautiful Soup directly within Power Automate flows.

## Key Features
- Efficient data extraction from HTML content
- Targeting specific elements using CSS selector syntax
- Alternative targeting using XPath expressions
- Conversion of HTML tables into structured data
- Finding, filtering, and extracting information from HTML elements
- Built-in capability to fetch HTML from URLs

## API Specifications
This connector uses a RESTful API that supports the following operations:

- fetch_html: Retrieves HTML from a specified URL
- select: Selects HTML elements matching a provided selector
- extract: Extracts specific attributes or values from selected elements
- find_all: Finds all elements matching a specific tag name and attributes
- parse_table: Converts HTML tables into structured data
