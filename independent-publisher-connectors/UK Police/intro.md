# UK Police - Connector Proposal

## Summary
This connector provides access to the UK Police public API at 
data.police.uk, covering crime, neighbourhood, force, and stop 
and search data across England, Wales, and Northern Ireland.

## API Details
- API URL: https://data.police.uk/api
- API Documentation: https://data.police.uk/docs/
- Authentication: Anonymous (no credentials required)
- Free to use: Yes

## Planned Operations
1. List all forces
2. Get specific force
3. Get force senior officers
4. Get street-level crimes
5. List crime categories
6. Get last updated date
7. List neighbourhoods
8. Get specific neighbourhood
9. Get neighbourhood team
10. Locate neighbourhood
11. Get stop and searches by force
