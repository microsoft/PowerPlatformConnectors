# Proposal - SharePoint Embedded (Independent Publisher)

Microsoft SharePoint Embedded is a cloud-based file and document management system suitable for use in any application. SharePoint Embedded is a new API-only solution that enables app developers to harness the power of the Microsoft 365 file and document storage platform for any app, and is suitable for enterprises building line-of-business applications and ISVs building multitenant applications.

More details about SharePoint Embedded can be found here: https://learn.microsoft.com/en-us/sharepoint/dev/embedded/overview

MSFT provided sample files can be found here - including the Postman file that can be leveraged for connector development.
https://github.com/microsoft/SharePoint-Embedded-Samples

## Proposal details

My understanding is that Microsoft may release a first-party connector in the future; however, this may not take place for some time. I would like to provide an independent publisher connector so that others can more easily leverage the benefits of SharePoint Embedded in their Power Platform projects.

There are quite a few endpoints available to work with SharePoint Embedded. Initially, I am looking to tackle container and file endpoints and plan to save eDiscovery endpoints for a later date.
