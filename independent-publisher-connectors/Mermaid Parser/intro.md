# Mermaid Parser (Independent Publisher)
The Mermaid Parser connector provides universal parsing capabilities for Mermaid diagrams, supporting 20+ diagram types including ERD, Class, Flowchart, Sequence, State, Gantt, Timeline, Mindmap, Architecture, and more. Extract structured data from any Mermaid diagram and convert to multiple output formats including JSON Schema, SQL DDL, TypeScript, C#, Python, GraphQL, and more.

## Publisher: Troy Taylor

## Prerequisites
There are no prerequisites needed for this service.

## Obtaining Credentials
No authentication is required for this connector. This is a code-only connector.

## Supported Operations
### Parse Mermaid Diagram
Parse any Mermaid diagram (20+ types) into structured data with comprehensive validation, entity extraction, and relationship analysis.

### Convert to Development Formats
Convert parsed Mermaid diagram entities to 18+ development platform formats including JSON Schema, SQL DDL, TypeScript, C#, Python, Java, Go, Rust, GraphQL, React, Vue, Swift, Dataverse Schema, Power Apps Formulas, and more.

### Invoke Advanced Parser Tools
Access specialized parsing tools via Model Context Protocol (MCP) JSON-RPC 2.0 interface with 6 advanced tools for diagram analysis and conversion.

## Known Issues and Limitations
- Some deeply nested diagrams may have parsing limitations
