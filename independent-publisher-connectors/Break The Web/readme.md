# Break the Web (Independent Publisher)
The Break the Web service provides real-time trending topics and news stories with structured current event data for AI applications. Get access to the top trending stories online or search for specific topics with MCP server support.

## Publisher: Troy Taylor

## Prerequisites
There are no prerequisites needed for this service.

## Obtaining Credentials
You will need to sign up for an API key on the [Break the Web developers portal](https://btw.co/developers/account).

## Supported Operations
### Get trending stories feed
Returns the current top trending stories from across the internet with real-time structured data about the most important news and events happening right now.

### Search trending topics
Search for current and historically trending stories based on a free-text query. Returns relevant stories matching your search criteria with both live and historical data.

### Invoke MCP Server
Sends JSON-RPC 2.0 requests to the Model Context Protocol server for tool execution and capability management. Compatible with Claude for Desktop and other MCP clients for AI assistant integration.

## Known Issues and Limitations
There are no known issues at this time.
