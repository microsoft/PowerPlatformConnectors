# Linkly (Independent Publisher)

Linkly is a link shortener and click tracker. This connector exposes the core of the Linkly REST API so flows can create branded short links, look them up, delete them, pull click analytics, and report conversions.

## Operations
- List workspaces
- Create or update a link (custom domain, slug, UTM parameters, retargeting pixels, expiry, Open Graph)
- Get a link
- List links
- Delete a link
- List custom domains
- Get click analytics (time series)
- Get click counts by dimension (country, city, platform, referrer, UTM and more)
- Report a conversion
- List conversions

## Authentication
API key, sent as a Bearer token in the Authorization header.
