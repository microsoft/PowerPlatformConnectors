# Proposal to add Microsoft Docs MCP Server as an independent publisher connector

This is a proposal to add the Microsoft Docs MCP Server as a connector to the Microsoft Power Platform.

The Microsoft Docs MCP Server is a remote hosted MCP server that provides structured access to Microsoft’s official documentation.  The server retrieves accurate, authoritative, and context-aware technical content for code generation, question answering, and workflow grounding.

[Microsoft Docs MCP Server GitHub repository] (https://github.com/microsoftdocs/mcp)
